# Atlas Research

A multi-agent research platform. Ask a question; a Planner, parallel
Researchers, a Writer and a Critic produce a cited report where every
claim links to its source passage, and every agent step is visible in
a live trace.

## Status
In development. See docs/architecture.md for the full design.

## Quick start (development)
1. Copy .env.example to .env and add your API keys.
2. Start services: docker compose up -d
3. More steps will be added as the project is built.
